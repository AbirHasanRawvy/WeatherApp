# WeatherApp
Try to create a manual weather app by using html, css and javaScript and also help from weatherapp.org. Here, further showing citys weather states.

# Getting Started
First run the developement server:<br>
From index.html click on "Open With Live Server".<br>
Open: http: http://127.0.0.1:5500/index.html with your browser to see the result.<br>
